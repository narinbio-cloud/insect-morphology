# Insect Morphology 3D

สื่อการสอนสัณฐานวิทยาภายนอกของแมลงแบบโมเดล 3 มิติ วิชา AG 002 203 แบ่งเนื้อหา 3 ระดับ

- ระดับ 1 พื้นฐาน: ชิ้นส่วนหลักของตั๊กแตน
- ระดับ 2 รูปแบบและการปรับตัว: หนวด ปาก ปีก ขา ทิศทางหัว ตามสไลด์ และด้วงงวง
- ระดับ 3 ลงลึก: ส่วนย่อย เส้นปีก การเกี่ยวปีก ปลายเท้า และรูปวิธานจำแนกอันดับ
